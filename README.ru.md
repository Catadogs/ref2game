# ref2game — обновлённая редакция для Codex

Создание 2D-ассетов, игровых прототипов и законченных сцен по скриншотам, видео и концепт-артам.

Форк [studioigor/ref2game](https://github.com/studioigor/ref2game). Исходный движок, примеры и скилл созданы **studioigor**; авторство и [лицензия MIT](LICENSE) сохранены. Изменения этого форка находятся в **`codex/`**. Редакция `claude/` сохранена в исходном виде.

## Установка

Отправьте агенту:

```text
Установи скилл ref2game из https://github.com/Catadogs/ref2game, используй папку codex/.
```

После установки вызовите `$ref2game`, приложите референс и укажите нужный результат. При ручной установке копируется вся папка `codex/` под именем `ref2game`; существующую версию сначала сохраните.

## Основные изменения

- Три режима: **ассеты**, **прототип**, **игровая сцена**.
- Выбранный пользователем движок сохраняется; точное повторение композиции отделено от стилистической адаптации.
- Анимация подбирается под задачу: обязательного рига для каждого объекта нет.
- Запуск на Windows без обязательного Bash; корректная работа путей с пробелами.
- Пустой набор QA больше не считается успехом; игровые сценарии проверяют ожидаемое поведение.
- Архив сохраняет исходные листы спрайтов, промпты и редактируемый проект; замена результата защищена проверками пути.

## Требования и проверка

Для браузерного варианта нужны Python 3.10+ с Pillow/NumPy, поддерживаемый Node.js и Playwright. SciPy требуется для анализа изображений, FFmpeg/ffprobe — для видео. Зависимости устанавливайте в локальное окружение проекта; доступные инструменты проверяет `doctor.py`.

Версия Playwright закреплена в `codex/scripts/package-lock.json`: установите её через `npm ci` в `codex/scripts`. Chromium можно установить через `npx playwright install chromium`. Для существующих пакета и браузера доступны `PLAYWRIGHT` и `REF2GAME_BROWSER`; на Windows также поддерживается выбор установленного Chrome/Edge.

```text
python codex/scripts/doctor.py
node codex/scripts/browser-check.mjs
python codex/scripts/test_workflow.py --browser
node codex/scripts/test-runtime.mjs
```

Проверены три браузерных шаблона, управление и запуск игры из распакованного архива. Подробности и ограничения — в [FORK.md](FORK.md). Готовые экспортёры Godot/Pyxel в комплект не входят.
